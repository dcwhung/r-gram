## 背景及目標

R Gram 係一個自用嘅 fan-made PWA，介面係一部經典唱片機，專門播香港樂隊 RubberBand 嘅專輯。播放端設計已經完成（HANDOFF v16），但設計階段冇處理三樣嘢：

1. 聲音同 MV 由邊度嚟
2. 封面、歌單、歌詞由邊個、喺邊度管理
3. 歌詞點顯示

今次要做嘅係一個完整產品：

| 部分 | 目標 |
| --- | --- |
| 播放端（Frontend PWA） | 按 HANDOFF 實作唱片機介面，播 R2 上面嘅音檔同 MV，顯示跟歌同步嘅歌詞 |
| 管理端（Backend + Admin） | Login 之後管理專輯封面、歌單、歌詞，將 R2 專輯資料夾入面嘅音檔 / MV 檔配對去歌曲，發佈畀播放端 |
| 媒體儲存 | 音檔同 MV 檔放 Cloudflare R2，按專輯分資料夾 |

### 已確認嘅架構決定（用戶 2026-11-24）

| # | 決定 | 內容 |
| --- | --- | --- |

| C2 | 播放端權限 | 自用，**唔設 login**；網址唔公開宣傳，R2 媒體用公開網址直接播 |

## 用戶故事（User Stories）

### 播放端

#### [US-001] 開 app 見到旗幟載入畫面

- **身份**：作為聽眾
- **目標**：我希望開 app 時見到 RubberBand 旗幟飄揚同載入進度
- **原因**：以便知道 app 載入緊，同時有招牌開場
- **操作流程**：開 app（0 步，系統自動）
- **驗收標準**：
    - [ ] 全畫面黑色旗幟 + 白色 logo 飄揚，底部有進度線同三位數百分比（HANDOFF §4.1）
    - [ ] 進度反映真實載入（內容資料 + 當前專輯封面 + 字體）🅰️ D8
    - [ ] 載入完成後成塊旗淡出，露出主頁
    - [ ] 只喺冷啟動出現；由背景返嚟唔再出 🅰️ D8
    - [ ] 內容資料載入失敗但本機有上次嘅資料 → 用上次資料入主頁；完全冇資料 → 顯示錯誤同重試掣

#### [US-002] 主頁唱片機

- **身份**：作為聽眾
- **目標**：我希望主頁見到當前專輯嘅 CD、碟名、年份、播放針同功能掣
- **原因**：以便一眼知道而家揀咗邊張碟，同埋可以做乜
- **操作流程**：0 步（主頁係預設畫面）
- **驗收標準**：
    - [ ] 版面、尺寸、位置按 HANDOFF §3、§4.2（1080 × 1920 基準按比例縮放）
    - [ ] 白底黑字；強調色用當前專輯嘅專輯色
    - [ ] 左上：碟名 → 年份 + 專輯色橫線 → 歌名（揀歌後）→ `TRACK nn · m:ss`（播歌後）；冇 App 名
    - [ ] 右上角全程顯示版本號，數值嚟自 build（唔可以寫死）
    - [ ] 重開 app 時回到上次嘅專輯同歌（唔自動播）🅰️ D12

#### [US-003] 用 Wheel 揀碟

- **身份**：作為聽眾
- **目標**：我希望用底部嘅字母 Wheel 轉去另一張專輯
- **原因**：以便喺十幾張專輯之間快速切換
- **操作流程**：① 㩒畫面底部開 Wheel → ② 轉動 Wheel 到想要嘅碟（2 步 ✅）
- **驗收標準**：
    - [ ] Wheel 外形、刻度、字母、揀中樣式按 HANDOFF §4.3
    - [ ] 每張已上架專輯佔一格，次序由管理端決定（預設按發行日期）🅰️ D3
    - [ ] 字母係標籤唔係索引：兩張碟可以同一個字母（例如兩張 F）🅰️ D3
    - [ ] 轉動時所有碟沿弧線移動，揀中嗰張最大，右邊嗰張永遠疊喺最頂
    - [ ] 左上碟名同年份、專輯色跟住揀中嘅碟即時轉
    - [ ] 打開 Wheel 嗰刻播放針同功能掣淡出，揀完歌縮返主頁先再出現，中途唔閃返出嚟
    - [ ] 冇封面嘅專輯用預設碟面（專輯預設色）

#### [US-004] 揀歌同播放

- **身份**：作為聽眾
- **目標**：我希望㩒碟面打開歌單，揀一首歌播
- **原因**：以便聽想聽嘅歌
- **操作流程**：① 㩒碟面 → ② 捲動歌單（預設已揀中上次 / 第一首，可以唔捲）→ ③ 㩒碟芯 play 掣（3 步 ✅；唔捲 = 2 步）
- **驗收標準**：
    - [ ] 歌單畫面（黑底白字、弧形排列、白色框線、碟芯 play 掣）按 HANDOFF §4.4
    - [ ] 捲動時隻碟跟住轉，左上歌名即時更新
    - [ ] 㩒 play 次序：閃專輯色 → highlight 完全淡走 → 隻碟縮返主頁 → 播放針抬起、單一方向轉到碟面、放低 → 隻碟開始轉、聲音開始（HANDOFF §4.4、§4.5）
    - [ ] 播放中：碟芯顯示 pause icon + 進度圈（真實歌曲長度）；左上音量條 + `TRACK nn · m:ss`；針頭小燈著專輯色
    - [ ] 㩒碟芯 pause：聲音停、隻碟停、播放針留喺碟面；再㩒由原位繼續
    - [ ] 未有音檔嘅歌喺歌單顯示為灰色、揀唔到 🅰️ D11
    - [ ] 音檔載入失敗：播放針返回泊位，顯示一行錯誤提示，唔會卡住

#### [US-005] 換碟再播（組合流程）

- **身份**：作為聽眾
- **目標**：我希望由一張碟轉去另一張碟揀歌播
- **原因**：以便跨專輯聽歌
- **操作流程**：① 開 Wheel → ② 轉 → ③ 㩒碟面 → ④ 捲動 → ⑤ play（**5 步 🟡**；最短 4 步：唔捲動）
- **4–5 步理由**：呢個流程係兩個獨立子流程接埋（US-003 揀碟 2 步 + US-004 揀歌播 3 步），各自都 ≤ 3 步。弧形歌單係設計稿確認咗嘅招牌畫面，用戶換碟後通常要揀歌，唔係一定播第一首。
- **已考慮嘅簡化方案**：

    | 方案 | 步數 | 結論 |
    | --- | --- | --- |
    | Wheel 揀中後直接播第一首 | 3 | ❌ 唔採用：跳過咗歌單，同設計稿流程唔同；轉 Wheel 途中經過嘅碟會誤播 |
    | 歌單打開時預先揀中上次播過 / 第一首，唔使捲就可以 play | 4 | ✅ 採用（已寫入 US-004） |
    | 主頁底部向上掃一下 = 開 Wheel + 開始轉（一個手勢） | 4 | 🅰️ 建議 P2，要先更新 mockup |

- **驗收標準**：
    - [ ] 換碟時如果有歌播緊：繼續播原本嗰首，直到新碟嘅歌㩒 play 先換 🅰️ D13

#### [US-006] 連續播放同鎖屏控制

- **身份**：作為聽眾
- **目標**：我希望一首歌播完自動播下一首，鎖屏同耳機都控制到
- **原因**：以便唔使成日攞起部機
- **操作流程**：0 步（系統自動）；鎖屏控制 1 步
- **驗收標準**：
    - [ ] 一首播完自動播同一張碟下一首有音檔嘅歌；最後一首播完就停，播放針返回泊位 🅰️ D10
    - [ ] 鎖屏 / 通知中心顯示歌名、碟名、封面；播放 / 暫停 / 上一首 / 下一首可用
    - [ ] App 喺背景或者鎖屏時繼續播

#### [US-007] 睇 MV

- **身份**：作為聽眾
- **目標**：我希望㩒 MV 掣喺一部復古電視入面睇當前嗰首歌嘅 MV
- **原因**：以便聽歌之外可以睇片
- **操作流程**：① 㩒 MV 掣（電視升起、開機、自動播）（1 步 ✅）；收返：① 㩒 stop（1 步 ✅）
- **驗收標準**：
    - [ ] 電視外觀、位置、開機 / 熄機效果、三粒掣（play / pause / stop）按 HANDOFF §4.6
    - [ ] 電視升起時唱片機停低：播放針返回泊位、隻碟滑行停、碟芯變 play icon、音量條同時間停住；後面成部唱片機變模糊
    - [ ] MV 係 R2 嘅影片檔，16:9 放喺 4:3 螢幕入面，上下黑邊，有掃描線；聲音嚟自影片本身
    - [ ] 機身下方顯示進度線（專輯色）、`MV` + 歌名、已播時間（真實長度）
    - [ ] 當前歌冇 MV 檔，或者未揀歌：MV 掣變灰、㩒唔到 ✅ C5
    - [ ] 㩒 stop 或者 MV 播完：熄機效果 → 電視落返去 → 模糊消失；唱片**唔會**自動繼續，停喺之前位置，用戶㩒碟芯 play 先繼續 🅰️ D6
    - [ ] 電視上面兩粒大旋鈕只係裝飾，唔可以操作 🅰️ D7
    - [ ] 電視三粒掣嘅感應範圍每粒 ≥ 44pt（外觀尺寸唔變）

#### [US-008] 睇同步歌詞

- **身份**：作為聽眾
- **目標**：我希望播歌時睇到跟住歌行嘅歌詞
- **原因**：以便跟住唱 / 睇歌詞
- **操作流程**：① 㩒歌詞掣（1 步 ✅）；收返：① 再㩒歌詞掣（1 步 ✅）
- **驗收標準**：
    - [ ] 畫面見 §Design Proposal P-1（**要先出 mockup 畀用戶確認先可以寫 code**）
    - [ ] 歌詞按 LRC 時間戳顯示，而家唱緊嗰行 highlight，換行時自動捲到位
    - [ ] 打開歌詞時歌繼續播（同 MV 唔同）
    - [ ] 用戶自己捲動後暫停自動跟隨，幾秒後或者下一行開始時恢復
    - [ ] 暫停時歌詞停喺當前行；轉歌時歌詞跟住換
    - [ ] 當前歌冇歌詞，或者未揀歌：歌詞掣變灰、㩒唔到
    - [ ] 歌詞同 MV 唔會同時開：開 MV 會收起歌詞

#### [US-009] 專輯資料（Info）

- **身份**：作為聽眾
- **目標**：我希望㩒 Info 掣睇到當前專輯嘅資料
- **原因**：以便知道發行年份、類型等；同時係放「非官方」聲明嘅位
- **操作流程**：① 㩒 Info 掣（1 步 ✅）
- **驗收標準**：
    - [ ] 畫面見 §Design Proposal P-2（**要先出 mockup 確認**）
    - [ ] 顯示：碟名、發行日期、類型、唱片公司、歌曲數目
    - [ ] 顯示 App 名「R Gram」、版本號、「Fan-made，非官方」聲明 🅰️ D2

#### [US-010] 收藏專輯

- **身份**：作為聽眾
- **目標**：我希望㩒 Favourite 掣收藏當前專輯
- **原因**：以便標記鍾意嘅碟
- **操作流程**：① 㩒 Favourite 掣（1 步 ✅）
- **驗收標準**：
    - [ ] 收藏咗：外圈著燈、心形轉著燈色（HANDOFF §4.2）；再㩒取消
    - [ ] 收藏狀態存喺本機，重開 app 仍然喺度；唔同裝置之間唔同步 🅰️ D5
    - [ ] 轉去另一張碟時，掣嘅狀態跟嗰張碟

#### [US-011] 安裝同自動更新

- **身份**：作為聽眾
- **目標**：我希望 app 可以安裝落主畫面，有新版自動更新
- **原因**：以便似原生 app 咁用，唔使手動清 cache
- **操作流程**：0 步（系統自動）
- **驗收標準**：
    - [ ] 可以安裝成 PWA（manifest、icon、全螢幕、直度鎖定）
    - [ ] 啟動、返回前景、定時檢查新版；有新版自動重新載入一次（有防 loop）
    - [ ] 播緊歌 / MV 時唔即時 reload，等停咗先更新 🅰️ D14
    - [ ] 畫面固定 `100dvh`，成頁唔會捲動
    - [ ] 管理端發佈新內容後，播放端下次啟動或者返回前景就攞到（唔使出新版）

#### [US-012] 減少動態同無障礙

- **身份**：作為聽眾
- **目標**：我希望開咗系統「減少動態效果」時 app 唔會有大幅度動畫，螢幕閱讀器讀到每粒掣
- **原因**：以便唔舒服或者有需要嘅人都用到
- **操作流程**：0 步
- **驗收標準**：
    - [ ] `prefers-reduced-motion`：旗幟靜止（只得進度）、隻碟唔轉（進度圈照行）、播放針 / 電視 / 歌單 / Wheel 轉場改為直接切換或者 ≤ 150ms 淡入淡出；設定一改即刻生效
    - [ ] 所有 icon-only 掣（Info、Favourite、MV、歌詞、play / pause / stop、碟芯掣、Wheel 提示）有 `aria-label`，停用時有 `aria-disabled`
    - [ ] 主頁掣感應範圍 ≥ 44pt
    - [ ] 鍵盤可以操作所有掣（桌面瀏覽器）

### 管理端

#### [US-101] Login

- **身份**：作為管理員
- **目標**：我希望用 Google 帳戶登入管理端
- **原因**：以便只有我改到內容
- **操作流程**：① 㩒「以 Google 登入」→ ②（Google 頁）揀帳戶（2 步 ✅）
- **驗收標準**：
    - [ ] 只有白名單 email 入到；其他帳戶見到「沒有權限」頁
    - [ ] 未登入時所有管理 API 回 401，畫面跳去 login
    - [ ] 可以登出；session 有期限，過期要重新登入
    - [ ] 登入後返回原本想去嘅頁

#### [US-102] 管理專輯

- **身份**：作為管理員
- **目標**：我希望新增、修改、排序、上架 / 下架專輯
- **原因**：以便控制播放端 Wheel 見到邊啲碟、乜次序
- **操作流程**：改資料：① 揀專輯 → ② 改欄位 → ③ 儲存（3 步 ✅）；排序：① 拖動（1 步 ✅）；上下架：① 撥掣（1 步 ✅）
- **驗收標準**：
    - [ ] 專輯列表顯示：封面縮圖、碟名、年份、Wheel 字母、上架狀態、完整度（歌數 / 有音檔 / 有 MV / 有歌詞）
    - [ ] 可改欄位：碟名、Wheel 字母、發行日期、類型、唱片公司、專輯色、R2 資料夾、上架狀態
    - [ ] Wheel 字母預設按規則自動計（英文名第一個字母；中文名第一個字），可以手動改
    - [ ] 專輯 id 建立後唔可以改（係本機收藏同續播嘅 key）
    - [ ] 刪除專輯要二次確認；已發佈過嘅專輯建議下架而唔係刪除

#### [US-103] 管理 CD 封面

- **身份**：作為管理員
- **目標**：我希望上載同更換專輯封面
- **原因**：以便碟面同專輯色用啱嘅圖，唔使靠第三方圖片連結
- **操作流程**：① 揀專輯 → ② 揀圖檔 → ③ 確認裁切並儲存（3 步 ✅）
- **驗收標準**：
    - [ ] 接受 JPEG / PNG / WebP；自動裁成正方形（可以調位置）；有大細上限，超過會講明
    - [ ] 上載後自動由封面抽主色做專輯色，可以手動改；播放端唔使再即時抽色
    - [ ] 即時預覽圓形碟面效果（連銀邊同碟芯）
    - [ ] 換封面唔會影響已發佈嘅版本，直到下次發佈

#### [US-104] 管理歌單

- **身份**：作為管理員
- **目標**：我希望新增、修改、排序、刪除一張專輯嘅歌
- **原因**：以便歌單資料正確
- **操作流程**：① 揀專輯 → ② 改歌（歌名 / 副題 / 歌號）→ ③ 儲存（3 步 ✅）
- **驗收標準**：
    - [ ] 歌曲列表每行顯示：歌號、歌名、副題、音檔狀態、MV 狀態、歌詞狀態

#### [US-106] 管理歌詞（LRC）

- **身份**：作為管理員
- **目標**：我希望為每首歌貼上或者匯入 LRC 歌詞
- **原因**：以便播放端顯示同步歌詞
- **操作流程**：① 揀專輯 → ② 開某首歌嘅歌詞 → ③ 貼上 / 匯入 `.lrc` → ④ 儲存（**4 步 🟡**）
- **4 步理由**：歌詞係逐首歌嘅長文字內容，要先揀到嗰首歌；明確嘅「儲存」防止貼錯嘢即刻蓋走有時間軸嘅歌詞。
- **已考慮嘅簡化方案**：

    | 方案 | 步數 | 結論 |
    | --- | --- | --- |
    | 貼上後自動儲存 | 3 | ❌ 唔採用：LRC 格式錯誤要用戶睇過先決定，自動儲存會蓋走舊歌詞 |
    | 專輯頁直接拖多個 `.lrc` 檔入去，按檔名歌號批量配對 | 2 | 🅰️ 建議 P1（US-107），大幅減少 262 首歌嘅工作量 |

- **驗收標準**：
    - [ ] 接受標準 LRC：`[mm:ss.xx]歌詞`；支援一行多個時間戳、`[offset:]`；其他 metadata tag（`[ti:]`、`[ar:]` 等）忽略
    - [ ] 儲存前驗證：最少一行有時間戳；時間戳格式正確；錯誤逐行指出（行號 + 原因）
    - [ ] 冇時間戳嘅純文字唔可以儲存做歌詞（✅ C4：只做同步歌詞）
    - [ ] 可以清除歌詞（二次確認）
    - [ ] 可以由其他專輯嘅同名歌複製歌詞（複製後獨立，時間軸可以各自改）
    - [ ] 編輯器旁邊可以播嗰首歌嘅音檔預覽同步效果（P1）

## 驗收標準

整體驗收（超出個別 US）：

1. 用戶喺 iPhone 安裝 PWA，由冷啟動行完：旗幟 → 主頁 → 開 Wheel 轉碟 → 入歌單 → 播歌 → 睇歌詞 → 睇 MV → stop → 繼續播歌，全程冇卡住、冇錯位，畫面同 `_mockups_/r-gram/index.html` 對應格一致
2. 管理員由 login 行完：改一張專輯嘅封面 → 掃描 R2 資料夾 → 貼一首歌嘅 LRC → 發佈；播放端重新開啟後見到新封面、播到新配對嘅歌、睇到新歌詞
3. 未登入或者非白名單帳戶改唔到任何內容
4. 播放端由 vN 自動更新去 vN+1 驗證通過
5. 開咗「減少動態效果」行一次第 1 項流程，冇大幅度動畫
6. 所有 4–5 步流程（US-005、US-106）嘅理由同簡化方案已記錄喺本文件
7. 新畫面（歌詞、Info、管理端）喺寫 code 之前已有用戶確認嘅 mockup

## Design Proposal

> 以下只係方向提案。按團隊 Preview-First 規則，每個都要先做靜態 HTML preview（`_mockups_/<feature>/index.html`）畀用戶確認，先可以寫 UI code。

### P-1 歌詞畫面 + 歌詞掣

- **入口**：左下掣列加第四粒掣（同一款拉絲鋁，x = 538，同其他三粒相隔 138），icon 係幾行文字；開咗外圈著燈；冇歌詞時變灰
- **畫面**：唱片機同標題變模糊再壓暗（沿用歌單頁嘅黑底白字），歌繼續播
- **歌詞**：直排一列置中偏左；而家唱緊嗰行白色、字級 42（Noto Sans HK 700），左邊有專輯色短橫線；其他行字級 32，越遠越淡（同歌單一樣嘅遠近處理）
- **動態**：換行時向上捲一行（≤ 300ms）；reduced-motion 直接切換
- **收返**：再㩒歌詞掣；掣列喺歌詞層上面保持可見

```
┌──────────────────────────┐
│ 碟名            v0.1.0   │  ← 模糊 + 壓暗
│ 2008 ──                  │
│ 歌名                     │
│                          │
│      上兩行（好淡）      │
│      上一行（淡）        │
│ ── 而家唱緊嗰行（白）    │  ← 專輯色短橫線
│      下一行（淡）        │
│      下兩行（好淡）      │
│                          │
│ (i) (♥) (MV) (詞)        │  ← 歌詞掣著燈
└──────────────────────────┘
```

### P-2 Info 畫面

- **入口**：Info 掣（開咗外圈著燈）
- **畫面**：同 P-1 一樣嘅模糊 + 壓暗層；歌照播
- **內容**（由上到下）：碟名（Lubalin 大字）→ 專輯色橫線 → 發行日期、類型、唱片公司、歌曲數目（細字標籤 + 值）→ 底部 `R Gram v0.1.0` + 一行「Fan-made，非官方」
- **收返**：再㩒 Info 掣

### P-3 管理端

- **方向**：沿用 903-player `apps/admin` 嘅視覺語言同元件做法（分段 tab、圖片格 + 裁切對話框、儲存條、Toast、確認對話框）；桌面為主，手機可用；介面文字用書面語
- **畫面**：

    | 畫面 | 內容 |
    | --- | --- |
    | 登入 | 「以 Google 登入」掣；冇權限頁 |
    | 專輯列表 | 封面縮圖、碟名、年份、Wheel 字母、上架掣、完整度；拖動排序；未發佈修改提示 + 發佈掣 |
    | 專輯頁 | Tab：資料（欄位 + 封面 + 專輯色 + 圓碟預覽）｜歌單（歌曲表 + 掃描掣 + 每首歌嘅音檔 / MV / 歌詞狀態）|
    | 歌詞編輯 | 左：LRC 文字框 + 逐行驗證；右：播放預覽（P1）；儲存 / 清除 / 由同名歌複製 |
    | 掃描結果 | 已配對、配對唔到嘅檔案、未有檔案嘅歌；手動指定 |
    | 發佈確認 | 變更摘要 + 警告 + 確認；發佈記錄（P1） |
