## Findings（冇 🔴 / 🟡）
- 🟢 S-148 封面載入失敗（圖片冇 CORS header、404、離線又未 cache）時，碟面出瀏覽器預設嘅「圖片載入失敗」圖示（拉到成隻碟大），唔係 `config/limits.ts:37` 講嘅「碟面先用專輯色」。Spec 冇講失敗時點顯示（冇 L1）→ backlog。部署要知：圖片同 `catalog.json` 都係 Worker 出、同一個 `PLAYER_ORIGINS`；漏咗播放端 origin = catalog 都攞唔到（冇副本出錯誤；有副本就入主頁但封面變呢個圖示）。截圖：scratchpad `qa034/shots/no-cors.png`
- Observation：IndexedDB `workbox-expiration` 係 Workbox 用嚟做 cache 上限嘅記錄（屬 Service Worker cache 機制）
- Observation：最長入主頁 15.0 s（catalog + 封面都冇回應）；spec 冇定上限，逾時常數見 review「逾時」一行（已接受）
- Observation：重試掣喺 360 闊得 41.3 px；同其他掣一樣用 390pt 基準（44.8pt）
- Observation：`components/flag` branches 77.19%（`FlagCanvas` 50%、`flagRenderer` / `useFlagAnimation` 71.42%）；已喺 B-075 ①。全域門檻 80% 冇 fail
- Observation（環境）：自簽證書嘅回應 Chromium 唔放 HTTP cache，所以每次都重新請求；令離線測試更嚴（只可以由 SW cache 出）
