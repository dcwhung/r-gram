## 🟡 Warning

### W-016 冇測試鎖住歌曲 route 喺 session 守門之後
- **位置**：`apps/api/src/api/routes.ts:222-229`；`apps/api/test/sessionGuard.test.ts:20-25`（401 路徑表只有 `/api/me`、`/api/albums…`）
- **L1**：US-101「未登入時所有管理 API 回 401」；backlog B-019 ①：守門靠註冊次序，新 route 一定要喺 `use('*')` 之後。
- **L2（實測）**：mutant M27 喺 `use('*', requireSession, requireSameOrigin)` 之前加 `apiRoutes.route('/tracks', trackRoutes)` → 11 個相關測試檔 165 tests 全綠。唯一守門測試係 `tracksCreate.test.ts:178` 嘅 POST 403（same-origin），冇 401，亦冇 `/api/tracks/*`。
- **影響**：而家 code 啱；但將來重排 `routes.ts` 會令歌曲 API 冇登入都用到，冇測試會紅。
- **方案 A（推薦）**：`sessionGuard.test.ts` 個路徑表加 `/api/tracks/x`、`/api/tracks/x/text`、`/api/albums/apollo-18/tracks`、`/api/albums/apollo-18/tracks/order`（GET / 寫入方法都要 401），CSRF 表加一個 `PATCH /api/tracks/x`。
- **方案 B**：寫一個測試由 `app.routes` 列出所有 `/api/*` route（除 `/api/health`），逐條冇 cookie 叫，期望 401。代價：要處理 path 參數，但新 route 自動包埋。
