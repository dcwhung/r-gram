## 指定檢查

- **歌號唔重覆**：靠 D1 嘅 `CREATE UNIQUE INDEX tracks_album_no`，新增同改歌號都係撞咗先處理，冇先讀後寫。兩個 PATCH 同時將兩首歌改做同一個號（P4）：`[200, 409 CONFLICT]`，最後 `2、3、7` 冇重覆。
- **錯誤先後次序**：
  - PATCH：body 唔係 object → 冇 If-Match → 欄位錯 / `MEDIA_NOT_FOUND`（400）→ 404 → 409 STALE → 409 `NUMBER_TAKEN`。If-Match 過時加撞號，回 STALE（有測試，P6 亦試過）；`UPDATE` 嘅 WHERE 唔中就唔會檢查 UNIQUE。
