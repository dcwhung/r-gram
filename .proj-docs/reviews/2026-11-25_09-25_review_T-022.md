## 🟡 Warning

### W-013 資料夾名收 `..`、`\`、`?`、`#`、`%`
- **位置**：`apps/api/src/albums/fieldRules.ts:82-86`（`folder` 只擋空白、控制字元、`/`）
- **L1**：Technical Spec「安全設計 → R2 key 驗證」：key 唔可以有 `..`。`folder` 係 R2 key 嘅 prefix（API-030 `MEDIA.list({ prefix: '<folder>/' })`，掃描結果寫入 `audio_key` / `mv_key`），播放端網址 = `MEDIA_BASE` + key。
- **L2（實測）**：`POST /api/albums {id:'x', title:'X', folder:'..'}` → 201，`folder: ".."`；`'a\b?#%'` → 201。
- **影響**：`../01 歌.m4a` 放入網址會被 URL 正規化跳出 `MEDIA_BASE` 嘅 path（自訂網域帶 path 時）；`?` / `#` / `%` 令網址斷開。要管理員自己打，所以係 Warning 唔係 Critical。
- **方案 A（推薦）**：`folder` 再擋 `.`、`..` 同 `\ ? # %`（新 reason 唔使，用 `INVALID_FOLDER`，i18n 句子補一句）；加測試。T-026 / T-030 砌網址時逐段 `encodeURIComponent`。
- **方案 B**：白名單字元（字母、數字、中文、空格、`-_.()`）且唔可以係 `.` / `..`。較嚴，但用戶 R2 入面已有嘅資料夾名可能唔合。

### W-014 冇專輯時 `PUT /api/albums/order {ids: []}` 回 500
- **位置**：`apps/api/src/albums/store.ts:81-84`（`db.batch([])`）
- **L1**：Technical Spec 錯誤列表：合法請求唔應該 500（`INTERNAL` 只畀冇預料嘅錯）。
- **L2（實測）**：空 D1 → `{"error":{"code":"INTERNAL"}}` 500。D1 batch 唔收空陣列。
- **方案 A（推薦）**：`if (ids.length === 0) return;` 加一個測試（空列表 → 200 `{ids: []}`）。
- **方案 B**：route 層 `ids.length === 0` 直接回 200。兩個都得，A 將限制留喺 store。

### W-015 後置 hook throw → 已儲存嘅寫入回 500
- **位置**：`apps/api/src/api/afterWrite.ts:35`
- **L1**：API-061「生成失敗……D1 嘅修改已經儲存，唔還原……觸發佢嘅寫入請求照回 200，但 `catalog.ok = false`」；D30。
- **L2（實測）**：hook `throw new Error('boom')` → 500，雖然 handler 已經寫入。而家係 `noPostWrite` 所以未觸發，但呢個接口就係 T-022 交付嘅嘢。
- **方案 A（推薦）**：`afterWrite` 包 try/catch：`catch (error) { console.error('[api] post-write failed', (error as Error).name); catalog = { ok: false }; }`；加測試。保證唔理 T-026 嘅 `rebuildCatalog()` 點寫都守到 spec。
- **方案 B**：喺 `PostWriteHook` 註解寫明「唔可以 throw」交畀 T-026。代價：靠紀律，冇測試鎖住。

// fieldRules.ts — W-013 方案 A
const UNSAFE_IN_FOLDER = /[/\\?#%]/;
const DOT_SEGMENT = /^\.{1,2}$/;
const folder: Rule = (value) => {
    const result = text(true)(value);
    if (!result.ok) return result.reason === 'TOO_LONG' ? result : fail('INVALID_FOLDER');
    const name = result.value as string;
    return UNSAFE_IN_FOLDER.test(name) || DOT_SEGMENT.test(name) ? fail('INVALID_FOLDER') : result;
};
// store.ts — W-014：D1 batch 唔收空陣列
export const writeOrder = async (db: D1Database, ids: readonly string[]) => {
    if (ids.length === 0) return;
    const statement = db.prepare('UPDATE albums SET sort_order = ? WHERE id = ?');
    await db.batch(ids.map((id, index) => statement.bind(index + 1, id)));
};
// afterWrite.ts — W-015：hook 失敗 = 已儲存但未生成（API-061）
const runHook = async (hook: PostWriteHook, c: Context<AppEnv>) => {
    try {
        return await hook(c);
    } catch (error) {
        console.error('[api] post-write step failed', (error as Error).name);
        return { ok: false };
    }
};
