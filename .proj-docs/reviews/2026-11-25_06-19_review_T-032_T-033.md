### W-010 隻碟嘅絕對數值冇跟設計稿放大 1.4 倍（`components/disc/Disc.tsx:8,52-66,86-87,102`；`app/TurntableShell.tsx:75-76`）

### W-011 暫停時封面彈返 0°，唔係停喺原位（`components/disc/Disc.tsx:23`、`disc/disc.css:7-11`）
- **L1**：Technical Spec:166「轉動用 CSS animation（`animation-play-state` 控制）」；Functional Spec US-004（:360）「㩒碟芯 pause：聲音停、隻碟停…再㩒由原位繼續」。呢點同 div / SVG 嘅偏離無關。
- **L2**：實測（headless Chromium，build 出嚟嘅頁）：播 1.35 秒後封面 `transform: matrix(0.019, 0.9998, …)`（約 89°）、`animation: disc-spin 5.4s running`；㩒暫停後 `animation-name: none`、`transform: none`。`grep -rn animation-play-state apps/player/src` 0 個結果。
- **L3**：`spinning` 只係加減 `disc-spinning` class，冇咗 class 動畫就消失，所以每次暫停封面跳返正，再播由 0° 開始。設計稿互動格都係咁做，但 spec 兩處都寫「停」。
- **方案 A（推薦）**：動畫長駐喺 `.disc-cover`，`data-spinning` 只切換 `animation-play-state`（仍然包喺 `no-preference` 入面）。**方案 B**：用 Web Animations API 記角度；多 JS，冇必要。
