## 🟡 Warnings

### W-036 碟面 `<image>` 用 no-cors 載圖，Service Worker 唔 cache 佢；睇過嘅碟，顯示中嗰張封面冇入離線 cache

- **位置**：`apps/player/src/components/disc/Disc.tsx:25`（`<image href>` 冇 `crossOrigin`）；`apps/player/src/pwa/catalogCaching.ts:27`（`statuses: [200]`）；`apps/player/src/catalog/usePrefetchOtherArt.ts:17-28`（只攞冇顯示嗰張）
- **L1**：FR-042、D56「兩張都入離線 cache」；backlog B-071 ①（今次負責收尾）
- **L2（靜態）**：build 出嚟嘅 `dist/sw.js` 入面，規則係 `CacheFirst` + `CacheableResponsePlugin({statuses:[200]})`。SVG `<image>` 冇 `crossorigin`，請求係 `no-cors`；跨 origin 拎返嚟嘅係 opaque 回應（status 0），所以唔會入 cache。用 `cors` 攞嘅只有兩個地方：Preload 攞第一隻碟揀中嗰張（`startupDeps.ts:25`），同 `usePrefetchOtherArt` 攞睇緊嗰隻碟**冇顯示**嗰張。所以第二隻碟之後，顯示中嗰張封面唯一嘅副本就係 HTTP cache。瀏覽器實測俾 hook 擋咗，要 QA S1 確認
- **L3**：下次開 app，第二隻碟有一半機會揀返同一張（D56 每次隨機）。離線時嗰張只可以靠 HTTP cache（`immutable`，通常仲喺度，但瀏覽器可以隨時清）。轉盤嘅縮圖（T-036）亦會用 `<image>`，會有同一個問題
- **方案 A**：`Disc.tsx` 嘅 `<image>` 加 `crossOrigin="anonymous"`。所有顯示嘅圖都用 cors，所以都會入 cache，以後轉盤縮圖都受惠。Worker 已經對 `PLAYER_ORIGINS` 回 CORS。代價：CORS 設定錯咗就連圖都顯示唔到（no-cors 至少見到圖）。要加一個測試檢查 attribute
- **方案 B**：`usePrefetchOtherArt` 兩張都攞（顯示中嗰張 + 另一張），用 cors，每張只攞一次。唔使改元件，但轉盤縮圖要另外處理
- **推薦**：A。改一行，所有顯示圖片都一致；CORS 已經係 B-071 ② 嘅前提
