## 新限制有冇拒絕 spec 容許嘅嘢

- **分鐘 2–3 位**：`[120:00.00]a` 收，`[1000:00.00]a` 報 `INVALID_TIMESTAMP`（有報錯，唔係靜靜哋掉）。Spec 格式係 `[mm:ss…]`，冇被拒絕嘅合法輸入。
- **offset 1–7 位**：`±9999999`（約 2.7 小時）收，`[offset: +250 ]`、`[OFFSET:250]`、寫喺檔尾嘅 offset 都照樣生效。Spec 只講支援 `[offset:]`，冇上限要求。
- **Base URL regex**：`https://pub-….r2.dev/`、自訂網域、`https://….workers.dev/catalog/v1/img/`、有 port、IPv6、路徑有 `%20` / `@` 都收；query、fragment、userinfo、空格、反斜線都拒。API-070 兩種例子都通過。
- **`generatedAt` / `releaseDate` / `wheelKey`**：`toISOString()` 嘅輸出、冇毫秒、`+08:00` 都收；`2024-02-29` 收、`2023-02-29` 拒；`A`、`電`、`18`、emoji 收，頭尾有空白嘅拒。真實 seed 資料砌出嚟嘅 catalog 仍然通過 validator。
- **收窄咗嘅 docs pattern**：只會令多啲 branch 跑 CI，唔會令 code 改動被跳過。而家同 `.prettierignore` / eslint ignores 範圍一致（`LICENSE` 冇 parser，Prettier 唔驗）。
- **先 sort 後 clamp**：`[offset:3000]` 之下四行嘅次序係 a、b、c、d，同原本時間先後一致。
