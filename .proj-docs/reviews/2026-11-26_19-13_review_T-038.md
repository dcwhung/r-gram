## 🔴 Critical

### C-001 D109 未做：畫面隱藏時自動下一首載入失敗照停，冇跳過一次

- **位置**：`apps/player/src/playback/playbackController.ts:304-307`（`error` 一律 `failed`）
- **L1**：Plan T-038 **P5**；Functional Spec D109（🅰️，U-25 未答照做）「畫面隱藏時自動下一首載入失敗（檔案冇咗、網絡錯）：跳去再下一首有音檔嘅歌試一次（最多跳一次），再失敗就停；前景照 US-004」
- **L2**：probe（scratch）：畫面隱藏 → 第 1 首播完 → 第 2 首 `fail('unsupported')` → `status: 'error'`、停喺第 2 首
- **要改**：controller 記「呢首係自動下一首、未出過聲」（`advanced` 設、`playing` 清）同「今輪已跳過」（`playing` 清）。`error` 時：`isHidden()` && 自動下一首未出聲 && 未跳過 && reason ≠ `blocked` → `nextTrack(queue, failedId, 'auto')`，有就 `engine.playNow()` + `advanced` + `session.track()`，冇（順序模式最後一首）或者第二次失敗 → `failed`。測試：隱藏 404 → 播再下一首；再 404 → `error`；前景 404 → `error`；順序模式最後一首 404 → `error`；Repeat One 唔會跳返同一首
- **方案 A（推薦）**：放 controller（隊列喺度、引擎保持唔識隊列，同 spike §2.7 一致）。代價：controller 多兩個 flag、約 20 行
- **方案 B**：引擎 `ended` 路徑自己再叫一次 resolver。代價：引擎要知「隱藏 + 跳一次」規則，違反 §2.7「隊列規則唔入引擎」

### C-002 D110 未做：鎖屏「上一首」永遠去上一首；`PREVIOUS_RESTART_S` 冇定義

- **位置**：`playbackController.ts:216-220`、`queue.ts:98-107`（註解仲寫「Q4 未答」）、`config/limits.ts`
- **L1**：Plan **P6**、**P7**（`PREVIOUS_RESTART_S` 喺 `config/limits.ts`）；Functional Spec D110
- **L2**：probe：第 2 首播咗 10 秒 → `previous()` → 換咗第 1 首
- **要改**：`limits.ts` 加 `PREVIOUS_RESTART_S = 3`；`previous()`：`engine.positionSec > PREVIOUS_RESTART_S` → `engine.seek(0)` + `session.position()`（唔換歌、唔 `advanced`）；否則照 `previousTrack()`；冇上一首（順序第一首）亦 `seek(0)`。Repeat One 唔受影響（只改 `previous`）。測試：3.5 秒 → seek 0；2 秒 → 上一首；正好 3 秒 → 上一首
- **方案 A（推薦）**：判斷放 controller（引擎已經畀 `positionSec`）。代價：約 8 行
- **方案 B**：`previousTrack(queue, id, positionSec)` 回 `{ restart: true }`。代價：純函數要知時間，queue 嘅「只理次序」變模糊

## 🟡 Warnings

### W-062 畫面隱藏時 `MEDIA_ERR_NETWORK` 即刻重設 `src` 重載

- **位置**：`apps/player/src/playback/audioEngine.ts:331-334`（`onError` → `retryOrFail()` 冇睇 `env.isHidden()`）
- **L1**：spike 報告 §2.3「錯誤：`MEDIA_ERR_NETWORK` → 同卡住一樣重試」＋「卡住：畫面隱藏時唔重載（903-player v1.20.8），等返前景或者鎖屏 `play` 先試」
- **L2**：probe：隱藏 → `fail('network')` → 即刻多一次 `play()`（`src` 重設）
- **方案 A（推薦）**：網絡錯誤時 `isHidden()` → `overdue = true`（`wantsSound` 照留），由 `retryIfOverdue()`／`play()` 接；**但**自動下一首未出聲嘅網絡錯誤要交 C-001（D109 明寫「網絡錯」都跳），所以引擎要照發 `error: network`（或者新增一個事件）畀 controller 決定。代價：要 Architect 確認呢個分界（見「要 owner 決定」①）
- **方案 B**：隱藏時一律照發 `error: network`，由 controller 決定跳（C-001）定等前景再 `restart`。代價：歌中途斷網會變「停 + 錯誤」而唔係返前景自動續

### W-063 D99：「3 秒內再播」唔會被舊 timer 放低 —— 冇測試鎖住

- **L2**：mutant M13（拎走 `clearTimeout` cleanup）全綠；probe 證明而家嘅 code 啱（舊 deadline 後 500 ms 仲係 `playing`）

- **方案 B**：`useEndedRelease` 單獨 `renderHook` 測 `runs` true → false → 推時間 → `release` 冇被叫。代價：唔覆蓋 useHome 接線
