## 🟡 Warnings

### W-037 向後轉一格：啱啱離開轉盤嗰隻碟俾 React 喺 DOM 拎走再插返，滑去弧線嘅過場好大機會冇咗

- **位置**：`apps/player/src/components/disc-stack/DiscStack.tsx:90-103`（唱片夾 slot 係固定 key `#slot` 嘅兄弟，緊接而家隻碟）
- **L1**：Functional Spec §CR-002「轉碟」：其他碟「沿弧線滑入」、「動態 0.5 秒」；設計稿 `svg.live [data-anim] { transition: transform .5s … }`（`template.html:76`），每隻碟都有過場
- **L2**：scratch clone 用 MutationObserver 重現：`current` 5 → 4（向後一格），formerly current 嗰隻碟（`f`）被 remove 再 insert；5 → 6（向前）只係搬 slot，碟冇郁。原因：React 排 key 嘅時候，舊次序 `… e f #slot g …` 變 `… d e #slot f g …`，`f` 嘅舊位置細過 `#slot`，所以搬嘅係 `f`
- **L3**：CSS Transitions 規格：元素離開 document 時取消佢嘅 transition，再插入就冇「改變前嘅樣式」，所以由轉盤（scale 1）去弧線（scale 0.72）會即刻跳位。每次向後轉都會見到。要 QA S1 喺瀏覽器確認
- **方案 A**：slot 嘅 key 跟住而家隻碟變（例如 `` `${SLOT_KEY}-${entry.albumId}` ``）：React 每格重新 mount 唱片夾，而唔係搬碟。唱片夾固定喺轉盤中心，重新 mount 睇唔到；代價係 Spindle 每格 mount 一次（`spindleRef` 跟住換，轉碟時 focus 喺旋鈕，唔受影響）
- **方案 B**：每隻碟自己一個 `<g key={albumId}>`，入面係碟 + （而家隻碟先有）children。DOM 次序永遠唔使搬；代價係要改 `HomeScene.test` 嘅「唱片夾緊接而家隻碟」嘅查法
- **推薦**：A（改一行），加一個 MutationObserver 測試：向後同向前轉一格，冇碟被 remove 再插返
