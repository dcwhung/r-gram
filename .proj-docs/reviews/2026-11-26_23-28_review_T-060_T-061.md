### W-068 Web Audio 路徑上，`cue` 嘅 `play()` 被拒之後，▶（同鎖屏 play）冇反應

- **位置**：`apps/player/src/mv/videoEngine.ts:85-97`（`reveal()`／`play()` 喺 `priming` 只設 `revealPending`，唔再叫 `element.play()`）；`mvController.ts:124-135`（status `paused`，唔係 `error`，所以唔會重新 `cue`）
- **L1**：開發者嘅決定（`mvController.ts` 頭註解、commit `9bfa1d9`）：「自動播被拒：停喺度等 ▶」；US-007 嘅三粒掣（▶ 要播得）
- **L2**：probe（scratch `src/review/probe.test.ts`，跑完已刪）：有 `AudioContext`，`element.playMode = 'blocked'` → `mv.open()` → status `paused`、`plays = 1`；改返 `auto` 之後 `mv.play()` → status 仍然係 `paused`，`plays` 仍然係 1（`expected 'paused' to be 'playing'`）。現有測試（`mvController.test.ts:177`）只驗冇 Web Audio 嗰條路（`primed` → `live`），所以冇發現
- **L3**：`onPlayRejected` 報 `blocked`，但 phase 留喺 `priming`；之後冇 `playing` 事件，`revealPending` 永遠用唔到。電視只可以㩒 ■ 收埋。`cue` 喺手勢入面，所以少見，但 iOS 慳電、權限或者焦點問題都有機會觸發
- **方案 A（推薦）**：`onPlayRejected` 喺 `priming` 時轉做 `primed`（`audio.hold(true)` 保持靜音）；之後 `reveal()` 行 `primed` → `live` 嗰條路，喺 ▶ 嘅手勢入面叫 `play()`。先加測試：「有 Web Audio、cue 被拒 → ▶ → playing，gain 去音量」
- **方案 B**：controller 收到 `blocked` 時記低，`play()` 照 `error` 一樣重新 `cue`，再 `reveal`。代價：重新設 `src`，會重新載入
- **Blocking**：唔阻 merge；建議 QA 之前修

### W-069 模糊用 `backdrop-filter`，唔係 D105 定嘅 `filter: blur()`（真機冇量過）

- **位置**：`apps/player/src/components/tv/tv.css:14-23`（`.tv-veil` `backdrop-filter: blur(calc(var(--u) * 20))`）
- **L1**：Functional Spec §CR-010 表 #5／D105：「用 CSS `filter: blur()`（真機兩種做法都係 60 fps，揀同 Technical Spec 一致嘅一種）」；Technical Spec「模糊背景（D105）」：「唱片機層 `filter: blur()` 照用……性能考量『瓶頸』② 關閉」，同「MV 電視過場」：「背後模糊層疊喺清晰層上面做 `opacity` 淡入淡出」；設計稿 `template.html:1892`：`filter="url(#fBackdrop)"` 套喺一份 ghost 上面
- **L2**：`grep -n "backdrop-filter\|filter: blur" components/tv/tv.css app/homeScene.css` → 只有第 21–22 行 `backdrop-filter`，冇 `filter: blur`。spike 報告 5b／5c 只量過 SVG filter 同 CSS `filter: blur()`
- **L3**：「瓶頸 ②」係因為量度咗嗰個做法先關閉；`backdrop-filter` 係第三個做法，Safari 每格都要重新取樣後面嘅內容。電視升起、天線彈出、CRT 動畫都喺模糊層上面同時進行，而且唱片機層每次 `timeupdate` 都會 re-render（S-260）。舊啲嘅 Safari 對 `-webkit-backdrop-filter` 入面用 `var()` 有已知問題（未驗）
- **方案 A（推薦）**：owner 接受 `backdrop-filter`，前提係 QA（U-24）喺真機用 spike 5b 嘅方法，量度電視開住同升起期間嘅 fps（≥ 55 fps）；量唔到就行方案 B
- **方案 B**：跟 spec：`.home-layer` 下面多 render 一份 `inert`、`aria-hidden` 嘅 ghost（或者喺電視開住期間對 `.home-layer` 本身用 `filter: blur()`，只淡入淡出上面嘅白色層）。代價：多一份 DOM，或者冇咗「清晰 → 模糊」嘅淡入
- **Blocking**：唔阻 merge；要 owner 決定或者真機數據
