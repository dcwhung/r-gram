## 4. 畫面同互動規格

### 4.1 Preload（旗幟）

| 項目 | 規格 |
|---|---|
| 畫面 | 全畫面黑色旗幟，印白色 RubberBand logo，飄揚 |
| 飄揚 | 布料網格（30×40 格），三組斜向波浪，有前後深度同摺位光暗；左邊旗杆位固定、右邊旗尾自由。參數喺 `FLAG`、`WAVE` |
| 載入指示 | 底部一條白色進度線＋三位數百分比 |
| 完成 | 成塊旗**淡出**（約 0.75 秒，同時輕微放大 5%），露出主頁 |

### 4.2 主頁

| 元件 | 位置／尺寸（1080 基準） | 行為 |
|---|---|---|
| CD | 圓心 (880, 1190)、半徑 740，佔右下大部分、右邊出界 | 入場由右下碌入；閒置時極慢自轉 |
| 左上資訊 | 左邊距 72，頂 92，成組縮到 2/3 | 碟名逐個字由下升起 |
| 播放針 | 軸心 (900, 330)，臂長 640 | **固定存在，冇入場動畫**。未播時打橫泊喺碟上方、針頭指左（176°），**唔掂碟面** |
| Info／Favourite／MV 三粒掣 | 左下，y = 1792，半徑 44；x = 124／262／400 | Favourite 揀咗：外圈著燈、心形轉著燈色。MV 見 §4.5 |
| Wheel 提示 | 底部置中一條細橫桿 | 㩒畫面底部打開 Wheel |

主頁專屬元件（播放針、三粒掣）由**打開 Wheel 嗰刻**一齊淡出，要到**揀完歌、隻碟縮返主頁**先再出現；中間由 Wheel 轉去歌單時唔可以閃返出嚟。

### 4.3 揀碟 Wheel

| 項目 | 規格 |
|---|---|
| 外形 | 淺色錶盤（唔係黑色），由底部升起嘅圓頂；闊 720（畫面闊度 2/3）、高 150 |
| 內容 | 白色邊圈、長短刻度（每張碟一條長、之間三條短）、深色字母 |
| 字母規則 | 專輯名第一個英文字母（A–Z）；中文名用第一個字（例：「電」） |
| 揀中 | 置中嗰格：字母放大（58 對 36）、刻度同頂部弧線標記轉專輯色 |
| 可見數量 | 同時見到約 5 個字母 |
| 轉動時嘅碟 | 所有碟沿一條弧線（半徑 1000、每張隔 30°）上落移動；揀中嗰張最大（半徑 620），前後嗰啲縮到 0.72 倍兼蓋一層白紗。**右邊嗰張永遠疊喺最頂** |
| 左上資訊 | 跟住轉換碟名同年份 |

### 4.4 歌單

| 項目 | 規格 |
|---|---|
| 進入 | 㩒碟面：Wheel 落返去，隻碟放大到圓心 (940, 1090)、半徑 1080，成個畫面轉黑再壓暗 80% |
| 排列 | 歌名沿住碟心嘅一條弧線排（半徑 520、每行隔 9.2°），喺畫面右半邊；上下各見約 4 行，越遠越淡 |
| 字級 | 揀中 42、其餘 32（歌號係字級嘅 0.72 倍） |
| 揀中標示 | 中間嗰行有**白色框線**（唔填色，高 88，左邊圓頭），框線右邊接住碟芯 |
| Play 掣 | 碟芯嗰個黑色實心夾就係 play 掣，上面有白色 play icon |
| 捲動 | 歌單沿弧線轉動，隻碟跟住一齊轉；左上歌名即時更新 |
| 㩒 play 嘅次序 | ① 框線同 play 掣閃一下專輯色 → ② **成組 highlight（框線、play 掣、歌單）完全淡走**（約 0.25 秒）→ ③ 之後隻碟先開始縮返主頁位置 |

### 4.5 播放

| 項目 | 規格 |
|---|---|
| 播放針 | 隻碟返到主頁後：抬起 → 由泊位（176°）**單一方向**向下轉到碟面（99°）→ 放低。放低之後隻碟先開始轉 |
| 碟芯 | 播緊顯示 **pause icon**；外圈淺色係全長，專輯色弧線係已播進度（由 12 點位順時針） |
| 左上 | 歌號變成三條音量條；下面出 `TRACK nn · m:ss` |
| 針頭 | 針頭上有一粒小燈，播放時著專輯色 |

### 4.6 MV 電視

| 項目 | 規格 |
|---|---|
| 觸發 | 㩒左下 MV 掣（外圈著燈） |
| 唱片機 | **停低**：播放針抬起返回泊位，隻碟滑行一下停，碟芯變返 play icon，音量條同時間停住 |
| 模糊層 | 電視升起時，後面成部唱片機連標題一齊變模糊再加一層淡白 |
| 電視位置 | 由底部彈上嚟（有回彈）；機身連腳佔畫面**下半**（y 962–1920），天線另計、伸上去疊住隻碟 |
| 電視外觀 | 五層：鋁邊機殼 → 凹入深灰面板 → 暖白色斜邊框 → 黑色膠邊 → 玻璃。螢幕上下邊明顯向外拱；玻璃有反光同暗角。兩支天線、兩隻向外斜嘅圓柱腳（有膠腳） |
| 開機 | 一條橫光線打開成畫面（約 0.45 秒） |
| MV 畫面 | 16:9 影片放喺 4:3 螢幕入面，上下有黑邊；有掃描線 |
| 控制 | 面板底部三粒按鈕，左到右：**play、pause、stop**，生效嗰粒外圈著燈 |
| 熄機 | 㩒 stop：畫面變白 → 壓成橫線 → 縮成光點 → 熄滅，全程約 0.28 秒；所有燈同時熄 |
| 機身下方 | 進度線（專輯色）、指示燈、`MV` ＋歌名、已播時間、一排散熱坑 |

## 7. 開發時要留意嘅設計風險

呢啲係由 preview 量出嚟、同用戶團隊規則（ai-dev-team plugin）有出入嘅位，寫 spec 時要逐項交代。

| 風險 | 數字 | 對應規則 |
|---|---|---|
| 觸控目標偏細 | 主頁三粒掣直徑 88px ≈ 32pt；電視 play／pause／stop 直徑 38px ≈ **14pt** | 一般建議最少 44pt；電視三粒掣一定要加大感應範圍 |
| 文字偏細 | 歌單 32px ≈ 11.6pt、Wheel 字母 36px ≈ 13pt、版本號 26px ≈ 9.4pt | — |
| 動畫時長 | 旗幟淡出 0.75s、電視彈出 0.8s、播放針 0.65s、歌單進出 0.7s | UX 規則要求 duration token ≤ 300ms；呢啲係招牌轉場，spec 要寫理由或者調短 |
| 流程步數 | 當前專輯揀歌播：㩒碟 → 捲動 → play = **3 步**。換碟再播：開 Wheel → 轉 → 㩒碟 → 捲動 → play = **5 步** | 3-Step Flow：4–5 步要喺 spec 寫理由同已考慮嘅簡化方案 |
| `prefers-reduced-motion` | Preview 只係停喺一格靜止畫面 | 真 app 要為旗幟、碟轉動、電視彈出提供減少動態嘅版本 |
| Icon-only 掣 | Info、Favourite、MV、play／pause／stop 全部冇文字 | 全部要 `aria-label` |
| PWA 規則 | 版本號而家係寫死 `v0.1.0` | 要改由 `package.json` build time 注入；另要自動更新、`100dvh` 固定畫面 |
| Design-Source Binding | — | UI PR 寫 `Design Origin: mockup:_mockups_/r-gram/index.html` |
